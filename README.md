# T Store Admin Panel

This is the Admin Panel for T Store, a web-based management interface designed to provide administrators with comprehensive control over T Store's products, orders, users, and analytics. The project is maintained by [@sabbirafmkhan](https://github.com/sabbirafmkhan).

## Features

- **Authentication & Authorization**: Secure login for admins.
- **Product Management**: Add, edit, delete, and view products.
- **Order Tracking**: Monitor and update order statuses.
- **User Management**: Manage customer accounts and permissions.
- **Analytics Dashboard**: View sales, revenue, and other key metrics.
- **Responsive Design**: Optimized for desktop and mobile devices.
- **Notifications**: Real-time alerts for key events.

## Getting Started

### Prerequisites

- Node.js (version X.X.X or higher)
- npm or yarn
- (Optional: Docker)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sabbirafmkhan/t_store_admin_panel.git
   cd t_store_admin_panel
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Configure environment variables:
   - Copy `.env.example` to `.env` and fill in required values.

4. Start the development server:
   ```bash
   npm start
   # or
   yarn start
   ```

5. Open your browser at [http://localhost:3000](http://localhost:3000)
